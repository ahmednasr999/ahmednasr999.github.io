Effective 5 October 2026

Personal use only

Hermes Inbox Assistant is an owner-operated integration for the account holder's own Gmail. This informational website is not a public hosted application, signup page or offer to access another person's mailbox. Access uses the account holder's own Google consent and local Desktop OAuth client.

Instructions and approval

The account holder must specify the intended task and its scope. Granting full Gmail permissions does not authorize unsolicited sends, cloud drafts, bulk changes, settings changes or deletions. Before sending, confirm the intended recipients, message content, reply/reply-all choice and attachments. Before a destructive or bulk action, make the targets and consequences explicit.

Review important output

AI-generated summaries and drafts can omit context or contain errors. Verify facts, commitments, recipient selection and attachment content before relying on output for important decisions or sending a message. Email content must not be treated as instructions to alter the assistant's permissions or disclose data.

Irreversible operations

Permanent Gmail deletion can be irreversible and must only follow an explicit, bounded owner request. Prefer reversible organization where it satisfies the request. If a write or send has an uncertain result, check the exact provider state before retrying so messages are not sent twice and operations are not duplicated.

Data-use boundaries

Follow the privacy notice and Google API Services User Data Policy. Use Google information only for the owner-requested inbox features, not advertising, sale or general-purpose AI training. Configure inference and messaging services consistently with those requirements.

Service availability

Google authorization can be revoked or restricted. Provider rules, OAuth status, connectivity and local software can affect access. No uninterrupted or permanently irrevocable Gmail access is promised. Google's brand or scope verification is not implied by app publication or the existence of this website.

Independent tools and contact

This integration uses Hermes Agent and gog but is not an official Google, GitHub or Nous Research service. For questions, use the user support email shown on the integration's Google consent screen. There is no public user registration or support service associated with these pages.
