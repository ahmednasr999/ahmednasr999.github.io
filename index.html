Private personal integration

Your inbox, under your direction.

Hermes Inbox Assistant connects a Google account holder's Gmail to their own Hermes Agent through the native gog command-line client. It is a personal tool, not a public email service.

Gmail onlyOwner-operatedNo public registration

What the integration does

Read and find

Search mail and read relevant messages, threads and attachment information for requests made by the account holder.

Draft and reply

Help prepare replies and, when specifically authorized, save Gmail drafts or send messages to the agreed recipients.

Organize with control

Manage labels, archive or trash messages and use available Gmail settings only within the account holder's requested scope.

Full access, bounded actions

The owner can grant full Gmail access, including permanent deletion. That capability is not permission for automatic deletion or other unsolicited mailbox changes.

Before sharing email with an assistant

OAuth credentials stay in the owner's native credential storage and restricted local files. Selected mail can be processed by the assistant's configured AI provider and can appear in requested chat responses and conversation history. AI inference must use privacy controls compatible with Google's Limited Use requirements.

This website does not request a Gmail login, hold OAuth tokens or call the Gmail API. Read the privacy notice for the data flow, retention and revocation controls.

How access is authorized

The account holder uses Google's standard OAuth consent flow for the local Desktop client. The website is informational only. The integration uses Hermes Agent and gog; this personal integration is not an official Google, GitHub or Nous Research service.

For access questions, use the user support email shown on the integration's Google consent screen. There is no public signup or invitation to connect another person's mailbox.
